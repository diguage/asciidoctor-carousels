Welcome! This page collects runnable examples for the AsciiDoc Carousels
extension. The project source is available on
https://github.com/diguage/asciidoctor-carousels[GitHub], and the gem is
published at https://rubygems.org/gems/asciidoctor-carousels[RubyGems]. Use
those links to find installation instructions, usage details, and the latest
releases.
